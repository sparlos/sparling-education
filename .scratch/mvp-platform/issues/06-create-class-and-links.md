# 06: Create a class and copy its links

**What to build:** A signed-in teacher creates a class by giving it a name and its grade or grades (3–5). Every game is turned on. The teacher can copy the class join link and a game link for any game in the class.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] A class has a name, one teacher, one or more grades, a join code and which games are on. All hosted games are on by default
- [ ] The teacher sees their classes and can create one in a single short form
- [ ] The class join link and each game link (one game, one class, carrying the join code) can be copied in one tap
- [ ] A teacher can only see and change their own classes (integration tested)
- [ ] The teacher port and its contract suite are extended. Rendered-app tests cover creating a class and copying links
